# Phethagatsa Solutions — Admin Operations Portal

Dedicated operations, inventory, and order fulfillment dashboard for Phethagatsa Solutions.

## Features
- **Overview Dashboard**: Live stats for total revenue (ZAR), active orders, customer count, low-stock alerts, and recent activity.
- **Product Inventory Management**: Add new products, edit price/stock, toggle featured, update images, and delete items.
- **Order Management**: Filter orders by status (Pending, Processing, Shipped, Delivered), update statuses, add The Courier Guy tracking numbers, and view complete order details.
- **Customer CRM**: View customer orders, lifetime spending, contact information, and membership tiers.
- **Analytics**: Revenue breakdown, top selling botanical formulas, and conversion metrics.
- **Store Settings**: Configure store name, WhatsApp concierge phone number, support email, address, and free delivery thresholds (R450+).

## Getting Started
```bash
npm install
npm run dev
```
Runs on `http://localhost:3002`.
