# Phethagatsa Solutions — Customer Storefront App

Modern African Skincare & Organic Wellness customer shopping application.

## Features
- **Hero Section**: Showcasing glowing radiant beauty portrait, Acacia brand tree identity, and trust badges.
- **Product Catalog & Filters**: Instant category filtering (Face Care, Body Care, Hair Care, Bundles, Supplements, Superfoods), search, and stock status.
- **Product Cards**: Tactile hover zoom, quick view drawer, direct Add-to-Cart, and direct WhatsApp order button.
- **WhatsApp Concierge & Global Button**: Floating direct chat with cart summary pre-filled in South African Rand (ZAR).
- **Customer Account Portal**: "Welcome back, Mpho!" profile overview with recent orders, wishlist, saved addresses, and loyalty points.
- **Checkout**: Single-page checkout with South African Instant EFT and card options.
- **Shipping & Care FAQ**: Accordion for delivery, returns, and organic balm care.

## Getting Started
```bash
npm install
npm run dev
```
Runs on `http://localhost:3001` (or integrated in the unified root workspace).
